## Central thesis

**Context engineering makes application modernisation repeatable, explainable and verifiable.** The four lenses determine whether the context is **meaningful** (ontology), **trustworthy** (epistemology), **appropriately governed** (axiology), and **useful to the people who depend on the system** (phenomenology).

## GitHub Pages

1. Create a **public** repository named `four-lenses-modernisation`.
2. Upload the contents of this ZIP into the repository root (not the containing folder).
3. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/(root)`.
4. The site should become available at `https://YOUR-USERNAME.github.io/four-lenses-modernisation/` after GitHub publishes it.

The book is a static app: `index.html` plus local image assets. Search, chapter navigation, dark mode and local-browser bookmarks work without a server. The `DISCLAIMER.md` page is directly readable at the repository URL; a dedicated HTML notice is also provided below for visitors.
